dml :-- data manipulation language :-- will used to perform operation on table data

insert   :-- will add the new data i.e record to table data

single record :
-----------------------------
>>>insert into table_name values(v1,v2,v3-----);

multiple records :--
------------------------
>>>insert into table_name values(v1,v2,v3----),(v1,v2,v3---),(v1,v2,v3-----);

selected column:
--------------------------
>>>insert into table_name(column_name1,column_name2) values(v1,v2);

update    :-- will used to modify existing data 
----------------------------------------------------

before using update or delete we need disable security options:
----------------------------------------------------------------
>>>set sql_safe_updates=0

to enable :--
---------------------
>>>set sql_safe_updates=1;


>>>update table_name set column_name=new_data where condition;

>>>update table_name set column_name=new_data,column_name=new_data where condition;


delete     :-- will used to delete the row based on condition
---------------------------------------------------------------
>>> delete from table_name where condition;



operators :-- will used to perform operation between operands 
-------------------------------------------------------------------

airthemetic   :-- will used to perform mathematical operation 
			(+,-,*,/,%)
relational    :-- will used compare the two values 
			(=,>=,<=,>,<,!= or <>) 
logical       :-- will check the condition is true or false
			and   :-- here all conditions must  be true
			or    :-- here at least one condition must be true
			not   :-- true --> false ,false --> true 

membership    :-- will check the value is present or not in group of values
			in     :-- will return true when values present 
			not in :-- will return true when values is not present 

identify      :-- will used compare the address
			is     :-- will check the address are same or not
			is not :-- will return true when address not same
