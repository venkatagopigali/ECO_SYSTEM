		will send the data into table after checking the condition

unique         :-- will not accept the duplicates 
		>>>will accepts the null values 
not null       :-- will not accepts the null values
		>>>will accepts the duplicates 
check          :-- will send the data into column after validate the condition
default        :-- will send a value automatically when cell is null
auto_increment :-- will assign number to row by default 1 to n no.of rows
