subqueries :-- a query inside the another query
		-->outer query
		-->inner query

single row    :-- will return the condition single row and single columns i.e. single cell
			(=,>,<,>=,<=,!= or <>)
multi row     :-- will return the condition as more then one row and single column
			(in, not in)
multi column  :--

case1 :-- condition will return single row and more then one column 
		(=,>,<,>=,<=,!= or <>)
case2 :-- condition will return as more then one row and more then one column 
		(in, not in)
