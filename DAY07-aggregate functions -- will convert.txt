aggregate functions :-- will convert the multiple cell information to single 			cell of information

sum()     :-- will add the all numbers (+) 
min()     :-- will return lowest values (<,>)
max()     :-- will return highest value (<,>)
avg()     :-- will calculate the sum of observation / no.of observation 
count()   :-- will count no.of cells contain data

>>>select count(*) from table_name;

			>>> unique + not null
