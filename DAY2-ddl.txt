datatypes :-- will identify the which data it is
---------------------------------------------------
number    :-- will accepts numerical type of data
-----------------------------------------------
int            :-- will used to store the number without decimal
			>>>4 bytes  >>>(2**31)-1
bigint         :-- will used to store the number without decimal
			>>>8 bytes  >>>(2**63)-1
float          :-- will used to store the number with decimal 
			>>>4 bytes  >>>(2**31)-1
			>>>will accepts 5 values after decimal point
double         :-- will used to store the number with decimal 
			>>>8 bytes  >>>(2**63)-1
			>>>will accepts more then 5 after decimal point
decimal(s,p)   :-- will used to store the number with decimal 
			>>>we can select no.of values after decimal 

string     :-- will accepts text type of data or collection of character 
		character :-- a single letter (alphabets,number,special symbols)
----------------------------------------------
varchar(size)  :-- will used to store the text type of data
			>>>255
char(size)     :-- will used to store the text type of data
			>>>255
			>>>fixed size
text           :-- will used to store the text type of data


date  :-- will used to store the date and time type data
