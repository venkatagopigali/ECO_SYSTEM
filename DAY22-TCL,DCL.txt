tcl :-- transaction control language 

>>>transaction :-- will used to perform operations on table data i.e insert,update,delete


commit     :-- will used to store data permanently 
		>>>commit;
rollback   :-- will used to get back or undo the data which stored as temperorily
		>>>rollback;
savepoint  :-- will used to store data temporarily
		>>>savepoint reference_name;

autocommit :-- 

disable the commit options :
-----------------------------
>>>set autocommit=0;


start the transaction :-- 
---------------------------------
>>>begin;
